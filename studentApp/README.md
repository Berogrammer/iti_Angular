1) SPA vs MPA

SPA (Single Page Application):
One page loads once, content updates without refresh.
✔ Fast, smooth user experience
✔ Example: Angular apps

MPA (Multi Page Application):
Each action loads a new page from server.
✔ Simpler structure


2) MVC vs MVVM (in Angular)

MVC:
Model → data
View → UI
Controller → controls logic
MVVM (Angular uses this):
Model → data
View → HTML
ViewModel → TypeScript (.ts) , data binding 


3) Component Files

.ts → logic + data
.html → UI (view)
.css → styling
.spec.ts → testing


4) Interpolation

    Used to display data in HTML
